Experiment 4 · Resample the evidence

Thirty alternate draws from the same sample

Use the class counts selected in the EM experiment. Each resample contains the same total number of observations, drawn with replacement, and gets its own abundance estimate. The original counts stay intact.

Uses a fixed seed (2026), so the same inputs reproduce the same result.

The range spans the smallest and largest estimates across 30 fits; it is not a confidence interval. If the evidence cannot distinguish two transcripts, identical starting weights can produce the same answer in every fit. A narrow spread alone does not establish certainty.
